# Factorio 2.1 compatibility

Preserves the existing prototype names and settings. Adapted to Factorio 2.1.24; private compatibility candidate.

Original source: https://mods.factorio.com/mod/WhatTimeIsIt; original author: CaptainDapper. Upstream license and assets retained.

Validation: native Factorio 2.1.24 fresh-world creation and isolated 1,200-tick probes. A native virtual-player GUI fixture also checks custom surfaces, renamed planet surfaces, platforms and return travel over 120 ticks. This does not establish graphical rendering or real multiplayer peer compatibility.

Public derivative whattimeisit-updated 1.0.0 preserves original authorship and license. Native migrates_from retains prototype identities and transfers owned objects; runtime controls adopt the complete original storage root. Literal prototype, setting, remote and metatable identifiers remain unchanged. Shared required dependencies and asset paths use the corresponding public derivative namespace. Original-ID feature validation remains in the private work directory; public native load validation is recorded separately.
